# Overseas Highway — Malaysia My Second Home (MM2H)

Premium Luxury, responsive, static website for Overseas Highway (M) Sdn. Bhd.

## Preview on GitHub Pages
1. GitHub repository > **Settings** > **Pages**.
2. Choose **Deploy from a branch**.
3. Choose **main** and **/(root)**, and save.
4. View https://overseashighway.github.io/MM2H/ after deployment finishes.

## Publish on cPanel
1. Download the repository as ZIP and extract it locally.
2. Open cPanel **File Manager** > **public_html** (or the document root of your intended domain).
3. Upload `index.html` into that directory. If you upload the whole ZIP, extract it and move the files into the document root, not a nested MM2H folder, unless that is the intended URL path.
4. Point the domain DNS to your hosting provider and enable SSL/HTTPS.
5. Confirm imagery, responsive layout, navigation, enquiry links and the official resources.

## Important before production
- Replace the **OH monogram** with your approved official brand logo.
- Confirm the destination enquiry email `info@overseashighway.net`. The current form opens an email client; it does **not** submit to a server or store leads.
- Insert a verified business WhatsApp number only after confirmation.
- Add a privacy notice, consent statement, and compliant lead form provider before collecting data online.
- Validate up-to-date MM2H requirements against official MOTAC material; note that programme categories and thresholds can change.
- Do not claim licensed MM2H application submission services unless your licence or approved partner arrangement has been verified.
- Verify image licences/permissions and use optimised owned media for production.
- Run browser tests on desktop, iOS and Android before paid traffic.

## Technology
Plain HTML, CSS and vanilla JavaScript. No build step, database or server runtime required for the informational website.

## Development
Edit `index.html`, commit changes to `main`, and GitHub Pages will publish the update if enabled.
